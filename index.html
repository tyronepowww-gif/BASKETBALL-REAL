Cartridge library

LOCAL JS

Built-in and user-installed cartridges provide real drill instructions. A cartridge is content, not a sensor or automatic measurement.

Install JavaScript cartridge

Paste a cartridge script and install it locally. Only install code you trust; custom scripts execute with page privileges.

Installed cartridge definitions are saved locally. The code itself is not re-executed at startup; validated drill data is restored from your save. Back up your profile before importing data from another source.

Cartridge API

Use TAP.registerCartridge({id,title,focus,drills}). Each drill needs a title, instructions, seconds, and optional metric. IDs must be unique. Maximum 30 drills per cartridge and 5 installed cartridges.
